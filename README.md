# 🧮 Calculadora Prática

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma **calculadora prática utilizando HTML, CSS e JavaScript**.

A interface foi criada para permitir a realização de operações matemáticas por meio de botões, apresentando os valores e resultados em um visor. O projeto também possui funções matemáticas como potência, porcentagem, raiz quadrada e valor absoluto.

## 🛠️ Tecnologias utilizadas

* **HTML5** — responsável pela estrutura da calculadora.
* **CSS3** — responsável pela estilização e organização dos elementos.
* **JavaScript** — responsável pela lógica e funcionamento dos cálculos.

## 📂 Estrutura do projeto

```text
calculadora/
│
├── index.HTML
├── style.css
└── script.js
```

### `index.HTML`

O arquivo HTML cria a estrutura principal da calculadora, incluindo o visor e os botões das operações matemáticas.

Entre as funções disponíveis estão:

* Adição `+`
* Subtração `-`
* Multiplicação `*`
* Divisão `/`
* Potência `x^y`
* Porcentagem `%`
* Raiz quadrada
* Valor absoluto
* Parênteses
* Limpeza do visor
* Resultado da operação

O HTML também utiliza o arquivo `style.css` para aplicar a aparência da calculadora e o `script.js` para executar suas funções.

### `style.css`

O CSS é responsável pela aparência da calculadora.

A página utiliza **Flexbox** para centralizar a calculadora na tela, enquanto os botões são organizados utilizando **CSS Grid**.
Também foram aplicados:

* Fundo para a página;
* Corpo da calculadora com bordas arredondadas;
* Sombra;
* Visor para exibição dos valores;
* Botões estilizados;
* Efeito `hover` nos botões;
* Organização em formato de grade.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Mantenha os arquivos `index.HTML`, `style.css` e `script.js` na mesma pasta.
3. Abra o arquivo `index.HTML` em um navegador.
4. Utilize os botões da calculadora para realizar as operações.

## 🎯 Objetivo do projeto

O objetivo deste projeto é praticar conceitos fundamentais de **desenvolvimento web**, principalmente:

* Estruturação de páginas com HTML;
* Estilização com CSS;
* Organização de elementos utilizando Flexbox e Grid;
* Criação de interfaces interativas;
* Integração entre HTML, CSS e JavaScript.
